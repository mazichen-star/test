# 材料力学性能预测系统

一个基于 Streamlit 的 Web 应用，面向材料研发与工艺优化场景。使用者无需编写机器学习代码，只需在浏览器中上传记录了"成分 / 工艺参数 -> 力学性能"的数据表，系统即可自动完成数据预处理、模型训练、效果评估与可视化，并支持对新样本进行力学性能预测。典型预测目标包括抗拉强度、屈服强度、弹性模量、延伸率等。

## 1. 项目概述

本系统的核心目标是把经典回归建模流程封装成一个可直接操作的网页工具：

- 上传 CSV / Excel 数据后，自动识别数值列与文本类别列，类别列自动做标签编码，目标列自动转为数值并剔除缺失行。
- 内置十类回归模型，可单独训练，也可同时训练多个模型并按测试集 R² 自动排名、选出最优模型。
- 输出 R²、MAE、RMSE 以及 5 折交叉验证 R² 等指标，并用图表解释模型。
- 训练完成后，可在表单中填入新样本的参数进行预测；留空的特征自动用训练集均值（类别列用众数）填充。
- 提供用户注册 / 登录 / 找回密码 / 修改密码 / 删除账号能力，用户上传的数据文件保存在云端，下次登录可直接加载。
- 界面支持中英文切换与暗色模式，并对窄屏做了响应式适配。

## 2. 技术栈

按职责分类如下：

- 前端与界面：Streamlit（Python 全栈式 Web 框架，直接渲染交互组件）、Matplotlib（绘制评估与解释图表）、自定义 CSS（暗色主题与响应式布局）。
- 后端与算法：Python、scikit-learn（各类回归模型、数据标准化、交叉验证、指标计算）、pandas / NumPy（数据读取与矩阵运算）。
- 数据库：Supabase（托管 PostgreSQL 数据库，通过其 PostgREST 提供的 HTTP 接口读写用户与文件数据）。
- 外部服务：SMTP 邮件服务（用于向绑定邮箱发送找回密码的临时密码）。
- 开发与部署：Git 做版本管理；可直接部署到 Streamlit Community Cloud，或在本地用 `streamlit run` 启动。

## 3. 项目架构

本项目为单文件 Web 应用，所有页面逻辑、模型训练与数据库访问都集中在 `app.py` 中，没有独立的后端服务进程。整体分为三层：

1. 表现层：Streamlit 负责登录注册页、侧边栏参数设置、数据预览、指标卡片、图表与下载按钮的渲染；多语言文案与暗色样式在文件顶部统一定义。
2. 建模层：`preprocess` 函数完成清洗、类别编码与标准化；`build_model` 按名称构造对应回归模型；训练后统一计算指标并绘制特征重要性、预测值对比、特征拟合曲线等图表。
3. 数据层：用户信息与历史文件通过 Supabase REST 接口持久化。密码以 SHA-256 哈希后存储；文件内容经 Base64 编码后存入数据库字段。

主要数据流：

```
用户上传文件
  -> pandas 读取 CSV / Excel
  -> preprocess: 清洗缺失值、LabelEncoder 类别编码、StandardScaler 标准化
  -> 划分训练集 / 测试集
  -> 选择单个模型或多模型对比训练
  -> 计算 R² / MAE / RMSE / 5 折交叉验证
  -> Matplotlib 可视化 + 导出含预测列的 Excel
  -> 训练好的模型与 scaler 存入会话，供新样本表单实时预测
```

Supabase 中使用两张表：

- `users`：存放用户名、密码哈希、绑定邮箱，用于注册、登录与找回密码。
- `user_files`：按用户名保存上传文件的文件名、上传时间与 Base64 编码内容，实现跨会话的数据文件复用。

## 5. 核心文件说明

### 5.1 入口与配置

- `app.py`：程序入口。直接运行后由 Streamlit 启动本地网页服务。文件顶部集中配置了 Supabase 连接信息与邮件发送函数；数据库地址、密钥和 SMTP 参数均可通过 Streamlit 的 secrets 覆盖，未配置 SMTP 时找回密码功能静默降级为在页面上显示临时密码。
- `requirements.txt`：声明运行所需的第三方库，安装命令见下文"快速开始"。
- `.gitignore`：排除 `__pycache__`、虚拟环境、`.env`、`data/` 与 `.streamlit/` 等本地文件，避免把密钥或数据提交到仓库。

### 5.2 数据模型与接口

应用不直接连接数据库驱动，而是用 `requests` 调用 Supabase 的 REST 接口，封装为一组函数：

- 用户相关：`user_exists`、`add_user`、`verify_user`、`change_password`、`delete_account`。
- 文件相关：`list_user_files`、`save_user_file`、`load_user_file`。
- 邮件相关：`send_email`，在找回密码时向绑定邮箱发送临时密码。

这些函数是前后端之间唯一的数据访问出口，后续若更换数据库，只需替换这组函数的实现。

### 5.3 核心业务逻辑

- `preprocess`：数据预处理核心。剔除目标列缺失的行，对非数值特征做标签编码，并在拟合 / 预测两种模式下复用同一套编码规则，保证训练与预测时特征口径一致。
- `build_model`：模型工厂，按名称实例化对应的回归算法。
- 支持的模型包括：线性回归、Ridge、Lasso、随机森林、梯度提升树、极端随机树、SVR 支持向量回归、核岭回归、MLP 神经网络，以及高斯过程回归（GPR）。
- GPR 额外提供 RBF 加白噪声、RBF 单尺度、Matern 3/2 三种核函数，并在预测时返回标准差，可绘制带 95% 置信区间的预测带；适合材料领域常见的小样本、需要量化不确定性的场景。

### 5.4 可视化与导出

- 特征重要性条形图（仅树模型输出）、预测值 vs 真实值散点图。
- 特征拟合曲线：固定其他特征为训练均值，单独扫描每个特征的取值，画出其对预测目标的影响，并自动标注曲线上的最大点与最小点，辅助判断工艺参数的最优区间。
- 预测结果明细表与一键下载的 Excel 文件，在原始数据基础上追加预测列（GPR 还会追加预测标准差列）。

### 5.5 关键组件

- 中文字体处理：启动时优先加载 `fonts/NotoSansSC-Regular.ttf`，找不到时回退到系统中文字体，保证不同操作系统与云端部署下 Matplotlib 图表中文正常显示。
- 会话状态：训练好的模型、标准化器、编码器与默认填充值存入 Streamlit 会话，使新样本表单无需重复训练即可实时预测。

## 6. 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动应用（在本目录下执行）
streamlit run app.py
```

启动后浏览器会自动打开本地页面。首次使用需先注册账号，登录后在左侧上传数据文件。

### 数据格式

每一行代表一个样本，每一列代表一个输入参数（化学成分、加工工艺参数等）或一个待预测的力学性能值。在页面中手动指定哪一列是"目标列"（要预测的性能），其余勾选为"特征列"（输入参数）即可。

### 可选的密钥配置

在本地新建 `.streamlit/secrets.toml` 可覆盖默认配置（该目录已被 git 忽略，不会提交）：

```toml
SUPABASE_URL = "https://your-project.supabase.co"
SUPABASE_KEY = "your-anon-key"
SMTP_HOST = "smtp.example.com"
SMTP_PORT = "465"
SMTP_USER = "your-mail@example.com"
SMTP_PASSWORD = "your-smtp-password"
```

## 7. 部署

将本目录推送到 GitHub 后，在 Streamlit Community Cloud 中选择该仓库、主文件设为 `app.py`，并在平台的 Secrets 中填入上述密钥，即可免费在线部署。
